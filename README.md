# 🎓 Portal Akademik Kelas 05TPLP009

Portal informasi akademik berbasis web untuk manajemen penugasan, pemantauan jadwal E-Learning Mentari, dan transparansi arus kas kelas 05TPLP009 (Teknik Informatika - Universitas Pamulang).

## 🚀 Fitur Utama
- **Manajemen Tugas:** Pantau tugas aktif, tenggat waktu (H-X), dan arsip tugas. Mendukung deskripsi dengan format Markdown.
- **Jadwal Mentari:** Sinkronisasi sesi e-learning, forum, dan kuis yang sedang berjalan.
- **Transparansi Kas:** Pencatatan otomatis iuran masuk dan pengeluaran operasional kelas.
- **Panel Admin:** Sistem CRUD terlindungi (Basic Auth) untuk mengelola seluruh data secara *real-time*.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** EJS (Embedded JavaScript), Tailwind CSS, Marked (Markdown Parser)
- **Database:** Turso (LibSQL / SQLite Edge Database)
- **Deployment:** Vercel (Serverless)
